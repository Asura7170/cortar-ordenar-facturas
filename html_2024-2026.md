# HTML 2024 – 2026: Elementos, Atributos y Novedades

Este documento recopila los **elementos, atributos, estados y características nuevas o mejoradas en HTML** desde **2024 hasta septiembre de 2026**, priorizando lo **soportado (o en camino) en Chrome**, incluyendo experimentales y origin trials donde aplica. Cada entrada incluye su uso y una descripción corta y directa.

> **Criterio:** Se incluyen elementos y atributos introducidos, implementados o significativamente ampliados en este período. Se marca con **(Experimental)** cuando está en origin trial o detrás de flag, y con **(Proto)** cuando es propuesta aún no implementada.

## 1. Elementos nuevos

### `<geolocation>` | Chrome 144
Elemento declarativo que ofrece acceso a la ubicación del usuario mediante un control controlado por el navegador, en lugar de una solicitud imperativa por script. **Uso:** obtener la ubicación del usuario con permiso explícito y con mejor recuperación tras denegaciones.

### `<usermedia>` | Chrome 151 (Capability Elements)
Elemento declarativo y activado por el usuario para acceder a cámara y micrófono, entregando el objeto `MediaStream` directamente. **Uso:** acceder a cámara/micrófono sin `getUserMedia()`, con mejor índice de recuperación de permisos.

### `<selectedcontent>` | Chrome 135 (customizable select)
Elemento hijo de `<select>` que permite personalizar cómo se muestra la opción seleccionada en el botón del control. **Uso:** mostrar en el botón del select un contenido distinto al de la lista desplegable.

### (Experimental) `<permission>` | Origin trial (PEPC, 2024)
Elemento genérico que incorpora un flujo de permiso controlado por el navegador, precursor de los "Capability Elements". **Uso:** solicitar permisos de forma declarativa y controlada por el navegador.

### (Proto) `<intrinsic-size>`
Elemento de ajuste de tamaño intrínseco para mejorar el maquetado y la estabilidad de layout. **Uso:** definir tamaños de reserva para contenido dinámico (propuesta ligada a la semántica de contenido).

### (Experimental) Web app HTML install element
Nuevo elemento para habilitar la instalación de aplicaciones web (PWA) de forma declarativa. **Uso:** permitir "Instalar app" desde el HTML sin depender solo de la barra del navegador.

### (Experimental) HTML-in-canvas
Nuevo primitivo que permite dibujar contenido HTML dentro de un canvas mediante métodos de dibujo y el evento `paint`; introduce el atributo `layoutsubtree`. **Uso:** renderizar HTML en canvas (2D, WebGL, WebGPU) para juegos o composiciones.

## 2. Atributos globales nuevos

### `popover` | Chrome 114+ (Baseline 2024-2025)
Atributo global que convierte un elemento en un popover con valores `auto`, `manual` y `hint`. **Uso:** mostrar contenido flotante superpuesto (menús, tooltips) sin JS propio.

### `popover="hint"` | Chrome (experimental → estable)
Tercer estado del atributo `popover`, pensado para tooltips/hints: no cierra otros popovers del stack. **Uso:** abrir un hint sin cerrar menús abiertos.

### `popovertarget` y `popovertargetaction` | Chrome 114+
Atributos de elemento que abren, cierran o alternan un popover de forma declarativa. **Uso:** controlar popovers desde botones sin JavaScript, con acción `show`/`hide`/`toggle`.

### `autocorrect` | Chrome 152 (global)
Atributo global que controla la autocorrección en elementos editables y `contenteditable`. **Uso:** habilitar o deshabilitar la autocorrección en inputs y áreas de texto.

### `closedby` | `dialog` y `popover` | Chrome 134+ (Baseline en proceso)
Atributo que define qué acciones del usuario cierran un diálogo: `any` (clic fuera o ESC), `closerequest` (ESC), `none` (sin cierre por el usuario). **Uso:** permitir "light dismiss" en diálogos modales.

### `command` y `commandfor` | Chrome 135+
Atributos que permiten a un elemento invocar un comando en otro (elemento con `id` objetivo): reemplazan a los viejos atributos declarativos y soportan acciones como abrir/cerrar diálogo o alternar popover. **Uso:** controlar elementos desde botones de forma declarativa, sin JS.

### `interestfor` e `interesttarget` | Chrome 142+
Atributos de "Interest Invokers": cuando el usuario muestra interés (hover/focus) sobre el elemento, se dispara una acción sobre el objetivo. **Uso:** abrir popovers/tooltips al pasar el mouse o enfocar, de forma declarativa.

### `inert` | (ya estable, ampliado en 2024-2026)
Atributo global que hace que un subárbol no sea interactivo ni enfocable. **Uso:** deshabilitar contenido (p. ej. secciones inactivas) y mejorar a11y de contenido oculto.

### `translate` | ampliado
Atributo que especifica si el contenido se debe traducir automáticamente. **Uso:** marcar contenido que no debe traducirse (marcas, código).

### `shadowrootslotassignment` | `<template>` | Chrome 151
Atributo para declarar shadow roots con asignación manual de slots (`named` o `manual`), evitando solo `attachShadow()` imperativo. **Uso:** definición declarativa de slots en declarative shadow DOM.

### `aria-actions` | Chrome 151
Atributo ARIA que asocia acciones disponibles a un elemento para tecnologías de asistencia. **Uso:** anunciar acciones accionables de un widget a lectores de pantalla.

## 3. Atributos por elemento

### `<input type="checkbox">` – `switch` | Implementado (Safari) / Chrome en camino
Atributo que convierte un checkbox en un interruptor nativo (switch) en lugar de una casilla. **Uso:** controles binarios on/off con estilo nativo.

### `<input type="search">` – atributo `search`/`appearance`
Atributos para mejorar el control de búsqueda (ya presentes y refinados en el período). **Uso:** definir el aspecto de un campo de búsqueda sin estilos de relleno.

### `<video>` y `<audio>` – `loading` | Chrome 148
Atributo que difiere la carga de recursos multimedia hasta que el elemento esté cerca del viewport. **Uso:** lazy loading de video/audio para ahorrar ancho de banda.

### `<select>` – `appearance: base-select` y modos
Modo "listbox" y nuevos rendimientos del `<select>` (Chrome 148) para render en página y estilizado completo. **Uso:** selects personalizables sin popups del navegador.

### `<details>` – `name` (accordion exclusivo) | Chrome 120+
Atributo `name` en grupos de `<details>` para que solo uno esté abierto a la vez. **Uso:** acordeones exclusivos sin JavaScript.

### `<img>` – `loading="lazy"`, `decoding` (ya estable, ampliado)
Optimizaciones de carga y decodificación de imágenes (mejoradas en 2024-2025). **Uso:** carga perezosa y decodificación asíncrona de imágenes.

### `title` – tooltip (`popover=hint` relacionado)
Mejoras para tooltips nativos próximas a interactuar con popovers declarativos. **Uso:** tooltips y micro-interacciones.

## 4. Atributos de formularios e inputs

### `popovertarget`
Permite conectar un botón con un popover declarativamente. **Uso:** abrir/cerrar popovers desde botones.

### `closedby` en `<dialog>`
Controla el light dismiss mediante clic fuera/ESC. **Uso:** diálogos que se cierran al hacer clic fuera.

### `commandfor` (en combinación con `command="request-close"`)
Valor de comando que cierra el diálogo objetivo de forma declarativa. **Uso:** cerrar diálogos desde botones "Cancelar"/"Cerrar".

### `input` – `switch`, `type="checkbox"` con estilo nativo
Da apariencia de interruptor a un checkbox. **Uso:** toggles nativos.

### `interestfor`
Formularios/tooltips que reaccionan a interés (hover/focus) del usuario. **Uso:** acciones en hover sin JS.

### `autocorrect` y `spellcheck` (relacionado)
Control de corrección automática y ortografía en campos editables. **Uso:** controlar sugerencias del teclado y editores.

## 5. Nuevos estados y valores de atributos

### `hidden="until-found"` | (ya estable, extendido 2024-2026)
Valor que oculta contenido pero mantiene la búsqueda "Find in page" y el acceso por fragmentos. **Uso:** contenido colapsado que sigue siendo buscable.

### `popover="hint"`
Véase sección 2 – estado adicional del atributo `popover` para hints (tooltips).

### `appearance: base-select`
Valor de CSS que habilita el nuevo rendering nativo del `<select>` estilizable. **Uso:** selects nativos completamente personalizables.

### `closedby="none" / "any" / "closerequest"`
Valores del atributo `closedby` para diálogos. Ver sección 2.

### `translate="no"`
Valor de `translate` para impedir traducción de contenido. **Uso:** proteger texto sensible a traducción automática.

## 6. Comandos y declarativos (atributos de comportamiento)

### `command` + `commandfor` (Invoker Commands)
Sistema para invocar comandos de forma declarativa desde un elemento invocador hacia uno objetivo (abrir, cerrar, alternar popover/diálogo...). **Uso:** eliminar JS para acciones UI comunes.

### `request-close` (comando de cierre)
Comando del sistema invocador que cierra el diálogo/popover objetivo. **Uso:** botones de cierre declarativos.

### `interestfor` / `interesttarget` (Interest Invokers)
API para relaciones hover/focus→acción sobre un objetivo (popovers, tooltips). **Uso:** comportamiento hover-driven SIN JavaScript.

### `popover` + `popovertarget` (Popover API)
API declarativa de popovers en top-layer. **Uso:** menús, tooltips, selectores flotantes con HTML puro.

## 7. Novedades de sintaxis y streaming

### Processing instructions `<?marker>`, `<?start>`, `<?end>` | Chrome 150 (experimental → en camino)
Nuevas instrucciones de procesamiento en HTML que sirven como plazas para actualizaciones de contenido dinámicas. **Uso:** streaming de HTML fuera de orden para "islas" de contenido.

### `<template for="...">` (out-of-order streaming) | Chrome 148+ experimental
Extensión del `<template>` que reemplaza placeholders definidos por processing instructions. **Uso:** inyectar HTML dinámico sin bloquear el parseo inicial.

### Escapado de `<` y `>` en atributos al serializar | Chrome 138 / Firefox 140
Cambio de seguridad en la serialización de HTML que escapa caracteres en atributos para prevenir inyección al reinsertar HTML serializado. **Uso:** prevenir XSS al volcar HTML en el DOM.

### (Experimental) Uso de `shadowRootSlotAssignment` en templates
Reflejo del atributo `shadowrootslotassignment` en `HTMLTemplateElement`. **Uso:** consultar/definir configuración de slots de shadow roots declarativas.

### (Experimental) HTML-in-canvas `layoutsubtree`
Nuevo mecanismo de renderizado de HTML en canvas (ver elemento). **Uso:** composición de UI sobre canvas.
