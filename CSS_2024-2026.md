# CSS 2024 – 2026: Cheatsheet de Novedades

Cheatsheet completo de todas las novedades de **CSS desde 2024 hasta 2026**, organizado por categorías: **selectores (pseudo-clases y pseudo-elementos), propiedades, valores y unidades, funciones, at-rules, comandos declarativos**, más una sección de **experimentales soportados en Chrome** e **Interop 2026**.

> Cada entrada indica la versión de **Chrome** en la que llega (o si es experimental / en camino). Los valores en `code` muestran sintaxis. Todo el contenido se verificó contra fuentes oficiales (Chrome, MDN, WHATWG en septiembre 2026).

## 1. Selectores – Pseudo-clases

### `:open` | Chrome 133
Selecciona elementos que están **abiertos/visibles**: `<details>` expandido, `<dialog>` visible y `[popover]` mostrado. Reemplaza combinaciones de `[open]` y `:popover-open`. **Uso:** estilizar contenido abierto con un solo selector.

### `:popover-open` | Chrome 114+ (reforzado 2024-2025)
Selecciona un elemento con `popover` que está **abierto**. **Uso:** animar/estilizar popovers mientras se muestran.

### `:target-current` | Chrome 135+ (scroll markers)
Selecciona el **marcador activo** que corresponde al elemento con scroll actual (usado con `::scroll-marker`). **Uso:** indicar la posición actual de un carrusel/índice.

### `:state()` (custom states) | Chrome 135+
Pseudo-clase funcional para estilizar **custom elements** según un estado interno (`element.states.set('active')`). **Uso:** estilos de componentes web según su estado.

### `:has()` (relacional, consolidado en 2024) | Chrome 105+
Selecciona un elemento cuando **contiene/relaciona** un elemento que cumple el selector entre paréntesis. **Uso:** estilizar padres según hijos, sin JavaScript.

### Pseudo-elementos seguidos de pseudo-clases (nuevo permiso) | Chrome 135+
Ahora se pueden escribir pseudo-clases después de un pseudo-elemento (ej. `::part(foo):hover` funciona de forma consistente). **Uso:** estilar partes de shadow DOM con pseudo-clases.

## 2. Selectores – Pseudo-elementos

### `::scroll-marker` | Chrome 135+
Representa un **marcador de carrusel** para un elemento dentro de un contenedor con scroll. Se agrupan en `::scroll-marker-group`. **Uso:** navegación de puntos/índice sin JS.

### `::scroll-marker-group` | Chrome 135+
Contenedor que agrupa los marcadores de un carrusel (se crea con `scroll-marker-group: after`). **Uso:** layout de los puntos de navegación.

### `::scroll-button()` | Chrome 135+
Pseudo-elemento funcional que genera **botones de scroll nativos** (`left`, `right`, `up`, `down`, `block-start`, `inline-end`, `*` para todos). Focales y deshabilitados automáticamente. **Uso:** flechas de carrusel con CSS puro.

### `::picker(select)` | Chrome 135+
Pseudo-elemento de la **lista desplegable** del select personalizable (se muestra en top-layer). **Uso:** estilizar el dropdown del `<select>`.

### `::picker-icon` | Chrome 135+
Ícono del **botón del select** personalizable. **Uso:** ocultar/personalizar la flecha del select.

### `::checkmark` | Chrome 135+
**Marca de verificación** en la opción seleccionada del select personalizable. **Uso:** estilizar la check del option seleccionado.

### `::details-content` | Chrome 131
Representa el **contenido** de un `<details>` (el área que se muestra al abrir). **Uso:** animar estilos del contenido expandible.

### `::highlight(<name>)` | Chrome 105+ / mejorado
Pseudo-elemento para estilizar rangos de texto resaltados por el **CSS Custom Highlight API**. **Uso:** resaltar búsquedas o texto de colaboración.

### `::view-transition-group()` / `::view-transition-image-pair()` / `::view-transition-old()` / `::view-transition-new()` | Chrome 111+
Pseudo-elementos del **sistema de view transitions** para animar la salida/entrada de elementos. **Uso:** transiciones SPA/MPA con CSS.

### `::backdrop` (herencia) | Chrome 122 (cambio)
`::backdrop` ahora **hereda** propiedades heredables (incluyendo custom properties) del elemento (dialog/popover). **Uso:** estilizar el fondo de modales con variables heredadas.

## 3. Propiedades

### `field-sizing` | Chrome 123
Controla el dimensionado de campos de formulario: `content` hace que crezcan con su contenido. **Uso:** textareas auto-crecientes sin JS.

### `text-box` (`text-box-trim`, `text-box-edge`) | Chrome 133
Alinea y recorta texto con precisión tipográfica (simetría de cap-height y baseline). **Uso:** centrar texto verticalmente sin hacks.

### `scrollbar-width` | Chrome 121
Ancho de scrollbar nativa (`auto`, `thin`, `none`). **Uso:** barras de scroll delgadas o ocultas.

### `scrollbar-color` | Chrome 121
Color de las partes de la scrollbar. **Uso:** scrollbars personalizadas sin pseudo-elementos.

### `scroll-marker-group` | Chrome 135+
Posición del grupo de marcadores (`before` / `after`). **Uso:** dónde aparecen los puntos del carrusel.

### `reading-flow` | Chrome 137
Controla el orden de **tabulación/lectura** de hijos en flex/grid (`flex-visual`, `grid-rows`). **Uso:** accesibilidad con orden visual distinto al del DOM.

### `corner-shape` | Chrome 147
Formas de esquina no solo redondeadas: `round`, `scoop`, `bevel` (y `notch`, `scoop`). **Uso:** esquinas creativas con una sola propiedad.

### `border-shape` | Chrome 147
Forma del borde para **bordes no rectangulares** (complementa `corner-shape`). **Uso:** bordes curvos/orgánicos.

### `column-rule` / `row-rule` (Gap Decorations) | Chrome 147
Estila los **huecos entre tracks** de grid/flex con líneas tipo `column-rule`. **Uso:** separadores entre celdas sin elementos extra.

### `container-type: scroll-state` | Chrome 136
Nuevo tipo de contenedor para **scroll-state container queries**. **Uso:** detectar estados de scroll (sticky, snapped, overflow).

### `anchor-name` / `position-anchor` | Chrome 125+
Propiedades de **anchor positioning** (posicionar un elemento respecto a un ancla). **Uso:** tooltips y dropdowns anclados sin `position` hacks.

### `position-area` / `position-try` / `position-visibility` | Chrome 125+
Colocación y estrategias de respaldo del elemento anclado. `@position-try` define fallbacks y `position-try-fallbacks` los aplica. **Uso:** posicionamiento adaptativo del anclado.

### `anchor-size()` | Chrome 125+
Función de tamaño relativo al ancla (puede usarse en `width`/`height`). **Uso:** elementos dimensionados al tamaño del ancla.

### `interpolate-size` | Chrome 129
Permite animar tamaño a `auto` (`allow-keywords`). **Uso:** transiciones de altura/width con `auto`.

### `content-visibility` (incluye `hidden=until-found` relacionado) | Chrome 85+ / mejorado
Evita render de contenido fuera de pantalla (`auto`, `hidden`). **Uso:** rendimiento en listas largas.

### `ruby-align` / ruby line-break | Chrome 128 (mejoras)
Controla la alineación de anotaciones ruby. **Uso:** tipografía japonés/notas al pie con mejor ajuste.

### `paint-order` | Chrome 131 (mejoras)
Orden de pintado de trazo/relleno (para texto con contorno). **Uso:** texto con stroke sin tapar el fill.

### `grid-lanes` (display) | Safari 26.4, Chrome en flag
`display: grid-lanes` para **masonry nativo** (relleno por lane). **Uso:** galerías masonry sin JS.

### `zoom` (restaurado) | Chrome 127+ (reintroducido como propiedad)
Escalar un elemento (`zoom: 1.5`). **Uso:** escalar UI sin afectar layout de forma compleja.

### `overflow-clip-margin` / `overflow: clip` (mejoras) | Chrome 90+
Controla el margen de recorte de contenido con `overflow: clip`. **Uso:** recortar sin scrollbar.

### `text-wrap` (mejoras) | Chrome 114+ consolidado
`text-wrap: balance` (equilibra líneas) y `pretty` (evita viudas). **Uso:** títulos y párrafos mejor balanceados.

### `font-size-adjust` (mejoras) | Chrome 127+ (reforzado)
Ajusta tamaño de fuente para consistencia entre familias. **Uso:** tipografía uniforme entre fuentes.

## 4. Valores y Unidades

### `stretch` | Chrome 144 (keyword de tamaño)
Valor de `width`/`height` que hace que el elemento llene el bloque contenedor **respetando box-sizing**. **Uso:** reemplaza `width: 100%` con `box-sizing` correcto.

### `light-dark()` | Chrome 123
Función de color que devuelve un valor según el `color-scheme` (`light-dark(light, dark)`). **Uso:** colores de tema claro/oscuro con una línea.

### `oklch()` / `oklab()` (consolidado) | Chrome 111+ (Baseline 2025)
Espacio de color perceptualmente uniforme. **Uso:** paletas y variaciones de color más predecibles.

### `color-mix()` | Chrome 111+ (consolidado 2024)
Mezcla dos colores (`color-mix(in oklch, a, b)`) con espacio y porcentaje. **Uso:** variantes de color sin funciones Sass.

### `contrast-color()` | Chrome 147
Devuelve `black` o `white` según el contraste legible del color de fondo. **Uso:** texto legible automático sin cálculos manuales.

### Unidades nuevas/consolidadas en 2024-2026:
- `cqw`, `cqh`, `cqi`, `cqb`, `cqmin`, `cqmax` — unidades de **container queries**. **Uso:** tamaños relativos al contenedor.
- `dvh`, `svh`, `lvh` — unidades de viewport dinámicas. **Uso:** altura responsive respetando barras del navegador.
- `lh`, `rlh`, `rcap` — unidades de línea y cap-height. **Uso:** dimensionado relativo a tipografía.
- `1e3px` — notación **exponencial** para números grandes. **Uso:** valores compactos.

### `flex-wrap: balance` + `flex-line-count` | Chrome 150
`flex-wrap: balance` equilibra las líneas de un contenedor flex que envuelve; `flex-line-count` limita el número de líneas. **Uso:** líneas flex balanceadas sin JS.

## 5. Funciones

### `if()` | Chrome 143 (experimental → estable)
Condicionales dentro de valores de propiedades: `if(cond: fallback)` para estilos dinámicos. **Uso:** lógica en valores de CSS.

### `attr()` tipado | Chrome 133
Función `attr()` ahora soporta **tipos y unidades** (`attr(data-x type(<color>), red)`). **Uso:** leer atributos HTML como valores de CSS tipados.

### `sibling-index()` | Chrome 138
Devuelve el **índice** de un elemento entre sus hermanos. **Uso:** delays escalonados sin `nth-child`.

### `sibling-count()` | Chrome 138
Devuelve el **número total** de hermanos. **Uso:** anchos iguales o fórmulas entre hermanos.

### `shape()` | Chrome 135
Función para formas de clip-path con coordenadas en unidades CSS y curvas. **Uso:** formas complejas responsivas sin SVG.

### `anchor()` / `anchor-size()` | Chrome 125+
Funciones de **anchor positioning**: `anchor(edge)` y `anchor-size(size)`. **Uso:** posicionar respecto al ancla.

### `scroll()` / `view()` (Scroll-driven animations) | Chrome 115+ (Baseline 2026)
Funciones para `animation-timeline`: `scroll()` (por scroll del contenedor) y `view()` (por aparición en viewport). **Uso:** animaciones ligadas al scroll.

### `@function` / `--custom-function` (Custom Functions) | Chrome 138 (experimental)
Define **funciones reutilizables** con `@function --name(...) { result: ...; }` y se usan como `--name()`. **Uso:** lógica CSS reutilizable.

### `calc()` con contenedores y unidades | consolidado
`calc()` ahora combina unidades de contenedores, viewport y tipografía. **Uso:** cálculos complejos en una línea.

## 6. Reglas-@ (At-Rules)

### `@scope` | Chrome 143
Limitando el alcance de selectores: `@scope (.card) to (.card-content) { ... }`. **Uso:** estilos con límites, alternativa a BEM.

### `@starting-style` | Chrome 117+ (Baseline 2026)
Estilos de **estado inicial** para transiciones de entrada (desde `display: none`). **Uso:** animaciones de entrada sin flash.

### `@view-transition` | Chrome 126
Habilita **transiciones entre documentos** (MPA): `@view-transition { navigation: auto }`. **Uso:** transiciones entre páginas del mismo origen.

### `@property` | Chrome 85+ (consolidado 2024)
Registra **custom properties tipadas** con sintaxis, herencia y valores iniciales. **Uso:** variables tipadas y animables.

### `@position-try` | Chrome 125+
Define **fallbacks de posicionamiento** para anchor positioning. **Uso:** reposicionar elementos anclados cuando no caben.

### `@container` (scroll-state) | Chrome 136+
Container queries ahora incluyen **scroll-state** (`@container scroll-state(snapped: x)`). **Uso:** estilos según scroll dentro del contenedor.

### `@media (prefers-reduced-motion)` | consolidado
Media query para respetar movilidad reducida. **Uso:** animaciones accesibles.

### `@media` con `width`/`range()` | Chrome 104+ (consolidado)
Sintaxis de **range** en media queries (`@media (400px < width < 700px)`). **Uso:** breakpoints de rango legibles.

### `@when` / `@else` (CSS Conditionals — propuesta)
At-rules condicionales de Nivel 5 para estilos encadenados. **Uso:** prototipado de lógica CSS (en camino).

### `@mixin` + `@apply` | Chrome 146 (esperado)
Define bloques reutilizables: `@mixin --center { ... }` y `@apply --center`. **Uso:** como Sass pero nativo.

### `@layer` (mejoras) | consolidado 2024
Capas de cascada para ordenar prioridades. **Uso:** resolver conflictos de estilos.

## 7. Comandos Declarativos y APIs de UI

### Invoker Commands (`command` / `commandfor`) | Chrome 135
Atributos que permiten a un botón **invocar comandos** en otro elemento (abrir diálogo, popover, etc.) sin JS. **Uso:** UI declarativa.

### Comando `close` / `show-modal` / `show-popover` / `hide-popover` / `toggle-popover` | Chrome 135+
Valores de `command` que reflejan los métodos JS equivalentes. **Uso:** acciones sin JavaScript.

### `closedby` | dialog / popover | Chrome 134
Controla el **light dismiss** de diálogos: `none`, `closerequest`, `any`. **Uso:** cerrar diálogos con clic fuera o ESC.

### `popover="hint"` | Chrome 150 (experimental → estable)
Hints/tooltips que **no cierran** otros popovers (para capas efímeras). **Uso:** tooltips apilados sin conflicto.

### `interestfor` / `interesttarget` (Interest Invokers) | Chrome 142
Reactivos al **hover/focus** para disparar acciones sobre un objetivo. **Uso:** tooltips/hover cards declarativos.

### `interest-delay` / `interest-delay-start` / `interest-delay-end` | Chrome 142+
Propiedades CSS para controlar el retraso de los interest invokers. **Uso:** timing fino de hover.

### `ToggleEvent.source` | Chrome 133
Propiedad del evento `toggle` que indica el elemento que lo originó. **Uso:** saber quién abrió un popover/detalles.

## 8. Experimentales soportados en Chrome

> Features **experimentales pero ya utilizables en Chrome** (detrás de flag u origin trial). Úsalas con `@supports` para degradación segura.

### `flex-wrap: balance` | Chrome 150 (experimental → estable)
Equilibra las líneas de un flex que envuelve. **Uso:** contenedores flex balanceados.

### `flex-line-count` | Chrome 150 (experimental)
Limita el número de líneas que produce el flex-wrap balanceado. **Uso:** controlar height del flex.

### `if()` (condicionales) | Chrome 143 (experimental)
Condicionales inline en valores. **Uso:** lógica en propiedades.

### `@mixin` / `@apply` | Chrome 146 (esperado)
Mixins nativos. **Uso:** reutilización de bloques.

### `grid-lanes` | Chrome/Safari 26.4 (flag)
Masonry nativo. **Uso:** galerías tipo Pinterest.

### `border-shape` | Chrome 147 (early)
Bordes no rectangulares. **Uso:** formas orgánicas con borde.

### `corner-shape` | Chrome 147 (early)
Esquinas `round`/`scoop`/`bevel`/`notch`. **Uso:** tarjetas con formas creativas.

### `anchor-size()` | Chrome 125+ (algunas en flag)
Tamaño relativo al ancla. **Uso:** componentes dependientes del ancla.

### `view-timeline` / `scroll-timeline` (nombradas) | Chrome 115+ (consolidado 2026)
Timelines de scroll con **nombre** (`scroll-timeline: --foo`). **Uso:** animaciones por scroll en varios elementos.

### `@function` (custom functions) | Chrome 138 (experimental)
Funciones CSS propias. **Uso:** lógica reutilizable compleja.

### `color-mix()` y `relative color` | consolidado
Variantes de color. **Uso:** paletas dinámicas.

### `text-box` | Chrome 133+ (early en algunos)
Recorte tipográfico. **Uso:** centrado vertical de texto.

## 9. Interop 2026

Area de **interoperabilidad** entre Chrome, Firefox y Safari para 2026. Se enfoca en hacer estables features avanzadas:

- **Anchor Positioning** — consistencia entre motores.
- **Scroll-driven Animations** — Baseline en todos los navegadores.
- **`@starting-style`** — Baseline completo.
- **`@scope`** — Baseline.
- **`contrast-color()`** — Chrome 147, en camino.
- **`shape()`** — Baseline completo.
- **Relative color syntax (`oklch()`, `color-mix()`)** — Baseline.
- **Custom Highlight API** — mejoras de resaltado de texto.

**Uso:** conocer qué features son seguras en todos los navegadores en 2026.
