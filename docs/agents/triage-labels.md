# Triage Labels

Los skills hablan de cinco roles canónicos de estado. Este archivo mapea cada rol al string que usa este repo.

| Rol canónico | Label en este tracker | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Falta evaluación del maintainer |
| `needs-info` | `needs-info` | Esperando información del reporter |
| `ready-for-agent` | `ready-for-agent` | Especificado, listo para un agente AFK |
| `ready-for-human` | `ready-for-human` | Requiere implementación humana |
| `wontfix` | `wontfix` | No se va a hacer |

En este tracker el label se escribe en la línea `**Estado:**` del ticket.

## Categorías

Además del estado, cada ticket triageado lleva una categoría en `**Categoría:**`:

- `bug`: algo está roto.
- `enhancement`: feature o mejora.
